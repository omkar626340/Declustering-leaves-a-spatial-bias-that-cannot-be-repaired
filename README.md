# Declustering-leaves-a-spatial-bias-that-cannot-be-repaired
Code for “Declustering leaves a spatial bias that cannot be repaired”: MATLAB SHIFT_GSRM2 translation for the background map, five declustering algorithms (Gardner–Knopoff, Grünthal, Uhrhammer, Reasenberg, Zaliapin), b-value and rate-bias analysis, and OpenQuake hazard calculations.
